# AIChatOrb

React-компонент анимированной иконки AI-чата. Без дополнительных библиотек и изображений.

## Подключение

Скопируйте AIChatOrb.jsx в проект с поддержкой JSX.

```jsx
import AIChatOrb from './AIChatOrb';

<AIChatOrb state={chatState} size={48} />
```

## Состояния

- `idle`: нет активного запроса; базовое движение ожидания.
- `thinking`: запрос отправлен, ожидается первое содержимое ответа; активный вихрь.
- `answer`: ответ поступает или озвучивается; перетекание и пульсация.

Состояние задаёт приложение, компонент не определяет его самостоятельно.
После завершения ответа, ошибки или отмены верните `idle`.
При смене состояния на `thinking` или `answer` сфера один раз сжимается и возвращается к исходному размеру. Повторная передача того же состояния не запускает акцент заново.

## Параметры

- `state`: `idle` | `thinking` | `answer`, по умолчанию `idle`.
- `size`: диаметр в CSS-пикселях, по умолчанию 48.
- `className`, `style`: оформление внешнего элемента.
- `label`: доступное название, по умолчанию `AI assistant`.
- `decorative`: true, если иконка декоративная, например внутри кнопки с собственным доступным названием.

```jsx
<button type="button" aria-label="Открыть AI-чат" onClick={openChat}>
  <AIChatOrb state={chatState} size={48} decorative />
</button>
```

## Интеграция

1. Отправка запроса → `thinking`.
2. Первый непустой фрагмент ответа → `answer`.
3. Завершение потока → `idle`.
4. Ошибка или отмена → `idle`.

Если после генерации запускается озвучивание, держите `answer` до его окончания.
Для параллельных запросов или озвучивания приложение должно самостоятельно определить приоритет актуального состояния.

Компонент автоматически учитывает prefers-reduced-motion, видимость вкладки и выход за пределы экрана. При размонтировании освобождает анимации, слушатели и observer. Внутреннее движение ограничено 30 кадрами в секунду, разрешение адаптируется к размеру и ограничено 256 пикселями.
